## สิ่งที่ทดสอบ (ย่อ)

- จุดเข้าแบบอื่น: รอเด้งแล้วใช้ limit, ตั้ง limit ที่โซน SL เดิม, เข้าใหม่ตรงจุดที่โดน SL, กรองแท่งเบรกที่ยาวเกิน, SL เหนือ swing high — ไม่มีแบบไหนชนะฐานอย่างทนทาน
