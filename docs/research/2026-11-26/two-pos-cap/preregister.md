สัญญาณที่ถูกปฏิเสธเพราะเพดานรวม 10%: m2_set 2025–26 = 0, 2024–26 = 0, 2015–26 = 3 (ทั้งหมดในช่วง 2019–24); m3_set 2025–26 = 0, 2024–26 = 8, 2015–26 = 15 ปฏิเสธเพราะ daily stop = 0 ทุกเซลล์ทุกช่วง (ฐานก็ 0) ดังนั้นเพดานแทบไม่ผูก ที่ lot 0.01 การยกเพดานไม่สามารถเปลี่ยนผล m2_set ในช่วง 2025–26 / 2024–26 ได้ จึงเพิ่มตัวแปรปรับตามความเสี่ยงไว้เพื่อการตีความ (ด้านล่าง)

## สิ่งที่ไม่เปลี่ยน

ทุกอย่างเหมือน preregister ของ two-position-20261126 (กฎฐาน live 7fe09f7246068bc9, F2, F3, cooldown 30 นาที, 0.01 lot, spread 0.24, slip 0.10, swap, ทุน 400, SL ก่อน TP ใน M1, path ฐาน, นิยาม portfolio_m, F3 แบบชุด, hold-out 4 ช่วง, นิยามเดือนดีกว่า/แย่กว่า และตัดเดือนดีสุด) ตัวจำลอง `pm.py` คัดลอก portfolio_m จาก two_pos.py โดยไม่เปลี่ยนตรรกะ เพิ่มเพียงตัวนับการปฏิเสธ
Daily stop = live/harness: ไม่เปิดไม้ใหม่เมื่อยอดปิดแล้ว (ไม่รวม floating) ลดลงจากยอดตอนเริ่มวัน UTC ≥ 10% ของยอดเริ่มวัน คงไว้ 10% ทุกเซลล์ ไม่มีตัวแปร daily stop
เพดานรวม = Σ (R+slip) ของไม้ที่เปิดอยู่และยังไม่ถูกเลื่อน BE + ความเสี่ยงไม้ใหม่ ≤ cap × ยอดปิดแล้ว (ต่อการ fill) — เปลี่ยนแค่ค่า cap

## ทางผ่าน

Parity ก่อน: ฐาน 2025–26 +1898.96, 2024–26 +1826.95, max DD 224.89 และ m2_set_c10 2025–26 = 2567.92 ถ้าไม่ตรง หยุด

`m2_set_c15` ผ่านก็ต่อเมื่อครบทุกข้อ
1. Net สูงกว่าฐานทั้ง 2025–26 และ 2024–26
2. Max DD ไม่สูงกว่าฐานทั้งสองช่วง
3. Net/MaxDD สูงกว่าฐานทั้งสองช่วง
4. ส่วนต่างหลังตัดเดือนดีสุดยังบวกใน 2025–26
5. เดือนดีกว่า ≥ แย่กว่า ทั้งสองช่วง
6. ค่าข้างเคียงไม่แย่กว่า: m2_set_c125, m2_set_c20, m3_set_c15, m3_set_c20 net ≥ ฐานใน 2025–26
7. Hold-out รายงานครบ 4 ช่วง และไม่แพ้ฐานใน 2019–24

ถ้า `m2_set_c15` ไม่ผ่าน: คงกฎ live ห้ามรับค่าข้างเคียงที่ชนะโดด ๆ และห้ามแนะนำให้ยกเพดาน live
