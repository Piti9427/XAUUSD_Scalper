Realistic Execution & Go-Live Architecture

Practical engineering reality: Running the MT5 bot on a native Windows Cloud VPS with official MetaTrader5 C-extension, free ForexFactory JSON calendar, and real-time Telegram supervision.

Reality 01 · APIs ที่ใช้ได้จริง

APIs ฟรี & ตรงไปตรงมา

  • Exness MT5 IPC (Zero Cost): ใช้ package MetaTrader5 ของแท้รันบน Windows เชื่อมต่อผ่าน Shared Memory เข้า MT5 Terminal ของ Exness โดยตรง ได้ tick latency ต่ำที่สุด
  • ForexFactory Weekly Feed (Free): ดึงไฟล์ JSON ปฏิทินข่าวเศรษฐกิจฟรี ไม่ต้องเสียเงินซื้อ TradingEconomics API กรองข่าวแดง USD ได้แม่นยำ
  • Telegram Bot API (Free): ใช้ token ส่งข้อความเข้า channel ส่วนตัวผ่าน api.telegram.org ฟรี 100% ไม่มีค่าบริการ

Reality 02 · โฮสต์ที่รันได้จริง

Windows VPS (แก้ปัญหา Mac)

  • ทำไม Mac/Wine ไม่เหมาะ: pip install MetaTrader5 บน macOS ไม่รองรับ และ Wine บน Linux มักมีปัญหาจอ Xvfb ค้างเวลา MT5 auto-update
  • ทางเลือกที่เสถียรที่สุด: เช่า Windows Cloud VPS ($5–$10/เดือน) เช่น Contabo, Hetzner, หรือใช้ Exness VPS ฟรี ติดตั้ง MT5 + Python รันได้เสถียร 24/7
  • ทางเลือกสำรอง (MQL5 EA): ถ้าไม่อยากเช่า VPS เพื่อรัน Python ให้คอมไพล์ mql5/B1FinalEA.mq5 แล้วโยนเข้า MT5 ตรงๆ ไม่ต้องพึ่งพา Python

Step-by-Step Go-Live

  • Step 1 · Demo Account: เปิดบัญชี Exness Standard Demo ($200) บัญชี Exness-MT5Trial7 สัญลักษณ์ XAUUSDm
