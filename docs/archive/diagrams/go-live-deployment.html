Go-Live Deployment & Infra Architecture

Physical topology, external cloud APIs, Oracle Cloud VPS execution host with Dockerized Wine MT5, and phased Go-Live validation roadmap.

Pillar 01 · APIs & Broker

Data & Broker Gateway

  • Exness MT5 Gateway (TCP:443): Connects via native Python MetaTrader5 library to Exness-MT5Trial7 (Standard Demo, $200 equity, 1:1000 max leverage) on symbol XAUUSDm (100 oz contract, min 0.01 lot, 0 commission, qualified swap-free).
  • Forex News API (HTTPS:443): TradingEconomics & ForexFactory calendar feed. Blocks trade entries 30 minutes before and after high-impact USD events (CPI, NFP, FOMC).
  • Telegram & GWS APIs: Sends real-time deal confirmation cards to Trader's Telegram channel; logs trade audit entries to Google Sheets.

Pillar 02 · Execution Host

Oracle Cloud VPS & Docker

  • Cloud Infrastructure: Runs on Oracle Cloud Always-Free VM running Ubuntu 22.04 LTS (Ampere A1 ARM64 with 24GB RAM or AMD Micro with 4GB swap space to eliminate OOM).
  • Headless Wine 8.0 + Xvfb: Runs official 64-bit Windows MetaTrader 5 Terminal inside Docker container headlessly without requiring a full Windows OS license.
  • Outbox Staging (b1_outbox.py): Enforces strict order_check and pre-entry margin verification. Auto-managed by systemd watchdog (restart: unless-stopped).

Pillar 03 · Go-Live Roadmap

Phased Transition Gates

  • Phase 1 · Staging Dry-Run: Local probe validating order check math, broker symbol specifications, and zero-phantom alert coupling.
  • Phase 2 · Exness Demo Forward Test: 2–4 weeks continuous forward trading on Exness Standard Demo ($200) to measure real slippage, broker fill latency, and swap behavior.
  • Phase 3 · Risk & Invariant Review: Audit drawdown (< 40% / $80 limit) and verify 100% adherence to the 10% equity cap before human real-money GO decision.
  • Phase 4 · Real-Money Micro ($200): Switch credentials to Exness Real Standard Account with strict fixed 0.01 lot size and 24/7 Telegram kill-switch.
