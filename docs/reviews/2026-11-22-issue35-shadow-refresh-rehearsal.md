# Issue 35 รอบ 50 — ทดสอบรับข้อมูลเพิ่มในตัวรันเดินเงา

ทดสอบบน Mac ด้วยไฟล์ Exness Bid/Ask เก่า ต.ค. และ พ.ย. 2026 ใช้ตัวรันที่ลงทะเบียนพร้อมการตรวจ checksum เดิม โดยให้ชุดทดสอบใช้วันเริ่มและไฟล์สถานะของตัวเอง ทุนเริ่ม $200, 0.01 lot และกติกาเดิมทั้ง base+swap และ stress+swap

- เริ่มชุดทดสอบวันที่ 24 ต.ค. เวลา 00:00 น. ไทย ข้อมูลชุดแรกมี 6,179,324 quotes หลังขอบเริ่ม สถานะเป็น `collecting`
- เพิ่มไฟล์ พ.ย. จาก 20 พ.ย. เวลา 06:59:59.790 น. ถึง 21 พ.ย. เวลา 04:57:59.929 น. ไทย ได้ราคาเพิ่ม 777,398 quotes ตรวจข้อมูลซ้อนกันตรงและผลปิดก่อนขอบเดิมตรงกันครบสี่บัญชี
- เมื่อข้อมูลชุดทดสอบครอบคลุมครบ 28 วัน ตัวรันขึ้น `awaiting_buy_evidence` ทั้งสองต้นทุน เพราะยังไม่มีผล BUY ที่เข้าเงื่อนไข Native ปิด 13 ไม้ สุทธิ +$71.57 base / +$71.32 stress ส่วน range20 ปิด 3 ไม้ สุทธิ −$46.79 / −$46.90
- ส่งไฟล์ฉบับสั้นกว่ากลับเข้าทดสอบ ระบบปฏิเสธเพราะจำนวน quotes ช่วงที่เคยยืนยันขาดไป และไฟล์สถานะยังมี checksum เท่าเดิม

ทั้งหมดเป็นการทดสอบตัวรันย้อนหลัง วันเริ่มเดินเงาจริงยังเป็น 23 พ.ย. 2026 เวลา 00:00 น. ไทย ผลล่าสุดก่อนเวลาเริ่มคือ `registered` และ 0 quote หลังเวลาเริ่ม การเทียบ 4 สัปดาห์กับ native และหลักฐาน BUY ยังรอข้อมูลใหม่
