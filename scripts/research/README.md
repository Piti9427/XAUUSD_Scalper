# Frozen research modules

Existing paths and source bytes are part of campaign provenance. Group by role
through this index; do not move modules or add compatibility wrappers for layout.

| Module family | Responsibility |
| --- | --- |
| `c22_frequency_*`, `c22_tuning_*`, `c22_context*` | C22 candidate preparation, campaigns, policy and checkpoints |
| `breakout_*`, `rollover.py` | Frozen canonical entry, execution, risk and swap math |
| `reward156_*`, `campaign_signals.py` | Archived detector contracts and causal signal preparation |
| `native_frequency_*` | Actual shared MQL5 detector bridge plus modeled canonical replay |
| `smc_challenger_*` | Prepared SMC research frames and accounting validation |
| `pure_b1_*`, `b1_*` | Retained B1 experiments and target replay |
| Other catalogs/runners | Archived strategy research; existing interfaces retained |

Every new economic comparison includes modeled swap in both base and stress;
missing metadata blocks. Raw experiments/source snapshots/checkpoints are ignored
`runs/<campaign>/`, summaries `docs/reviews/*.md`. Existing frozen run snapshots
keep original paths. Latest candidate reports/config links are in
[`docs/README.md`](../../docs/README.md). Research outputs do not approve Demo
adoption, broker/native parity or real-money use.
